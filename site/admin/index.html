    지금 매장은

    손님 화면(홈·메뉴·매장 페이지)에 그대로 보입니다. 자동 측정이 아니라 직접 보고 올리는 값이라, 화면에는 "몇 시간 전 확인"이 함께 표시돼요.

    점검 중인 기기

    오늘 없는 메뉴 (누르면 품절 표시)

    창업 · 제휴 문의

    엑셀(CSV) 내려받기

    처음 여는 모임은 여기서 공개해야 손님 화면에 나옵니다. 영업·투자·데이트 목적이거나 연락처를 요구하는 모임은 비공개로 돌려 주세요.

    숨긴 글은 손님에게 보이지 않지만 기록은 남아요. 삭제하면 댓글까지 지워지고 되돌릴 수 없습니다.

    소식 · 공지 글

    여기 올린 글은 밍글 소식 페이지와 홈 화면에 나가고, 네이버·구글 검색에도 잡힙니다. 새 메뉴, 점검 안내, 모임 일정처럼 날짜가 있는 이야기를 올려 주세요.

    새 글

    비워 두면 날짜로 자동 생성돼요.

    대표 이미지

    새 탭에서 보기

    모든 페이지 맨 위 공지

    기기 점검, 임시 휴무, 새 메뉴처럼 손님이 꼭 봐야 하는 한 줄을 띄웁니다. 손님이 닫으면 같은 공지는 그 브라우저에서 다시 안 보여요. 저장 후 1분 안에 반영됩니다.

    미리보기

    메뉴 · 가격

    가격을 비워 두면 손님 화면에 "매장 가격표"로 나옵니다. 숨긴 메뉴는 메뉴 페이지와 품절 버튼 목록에서 빠져요. 저장하면 1분 안에 메뉴 페이지와 검색엔진용 화면이 함께 바뀝니다.

    사이트 소유 확인 코드

    네이버 서치어드바이저·구글 서치 콘솔에서 "HTML 태그" 방식을 고르면 나오는 코드를 붙여 넣으세요. <meta … content="…"> 한 줄을 통째로 붙여 넣어도 코드만 골라 저장합니다.

    등록 순서

    1. 네이버 서치어드바이저 (searchadvisor.naver.com) → 웹마스터 도구 → 사이트 등록에 https://hellomingle.kr 입력 → "HTML 태그" 선택 → 코드를 위 칸에 저장 → 1분 뒤 네이버에서 "소유 확인".
    2. 네이버 → 요청 → 사이트맵 제출에 아래 두 주소를, RSS 제출에 RSS 주소를 넣습니다.
    3. 구글 서치 콘솔 (search.google.com/search-console) → URL 접두어에 https://hellomingle.kr → "HTML 태그"로 확인 → Sitemaps 메뉴에 아래 두 주소 제출.
    4. 네이버 플레이스·카카오맵에 매장이 등록돼 있다면, 그 주소를 에 넣어 주세요. 검색엔진이 홈페이지와 매장을 같은 곳으로 묶어 봅니다.
    5. 새 글을 올린 뒤 빨리 검색에 나오게 하고 싶으면 네이버 → 요청 → 웹 페이지 수집에 글 주소를 넣으세요.

    페이지별 검색 제목 · 설명

    비워 두면 페이지에 원래 들어 있는 문구를 씁니다. 제목은 30자 안팎, 설명은 80~150자가 검색 결과에서 잘리지 않아요. 저장 후 1분 안에 반영되고, 검색 결과에 바뀌어 보이기까지는 며칠 걸릴 수 있습니다.
