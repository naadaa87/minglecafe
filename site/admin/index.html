    지금 매장은

    손님 화면(홈·메뉴·매장 페이지)에 그대로 보입니다. 자동 측정이 아니라 직접 보고 올리는 값이라, 화면에는 "몇 시간 전 확인"이 함께 표시돼요.

    점검 중인 기기

    오늘 없는 메뉴 (누르면 품절 표시)

    창업 · 제휴 문의

    엑셀(CSV) 내려받기

    처음 여는 모임은 여기서 공개해야 손님 화면에 나옵니다. 영업·투자·데이트 목적이거나 연락처를 요구하는 모임은 비공개로 돌려 주세요.

    숨긴 글은 손님에게 보이지 않지만 기록은 남아요. 삭제하면 댓글까지 지워지고 되돌릴 수 없습니다.

    소식 · 공지 글

    여기 올린 글은 밍글 소식 페이지와 홈 화면에 나가고, 네이버·구글 검색에도 잡힙니다. 새 메뉴, 점검 안내, 모임 일정처럼 날짜가 있는 이야기를 올려 주세요.

    새 글

    비워 두면 날짜로 자동 생성돼요.

    대표 이미지

    새 탭에서 보기

    모든 페이지 맨 위 공지

    기기 점검, 임시 휴무, 새 메뉴처럼 손님이 꼭 봐야 하는 한 줄을 띄웁니다. 손님이 닫으면 같은 공지는 그 브라우저에서 다시 안 보여요. 저장 후 1분 안에 반영됩니다.

    미리보기

    메뉴 · 가격

    가격을 비워 두면 손님 화면에 "매장 가격표"로 나옵니다. 숨긴 메뉴는 메뉴 페이지와 품절 버튼 목록에서 빠져요. 저장하면 1분 안에 메뉴 페이지와 검색엔진용 화면이 함께 바뀝니다.

    사이트 소유 확인 코드

    네이버 서치어드바이저·구글 서치 콘솔에서 "HTML 태그" 방식을 고르면 나오는 코드를 붙여 넣으세요. <meta … content="…"> 한 줄을 통째로 붙여 넣어도 코드만 골라 저장합니다.

    등록 순서

    1. 네이버 서치어드바이저 (searchadvisor.naver.com) → 웹마스터 도구 → 사이트 등록에 https://hellomingle.kr 입력 → "HTML 태그" 선택 → 코드를 위 칸에 저장 → 1분 뒤 네이버에서 "소유 확인".
    2. 네이버 → 요청 → 사이트맵 제출에 아래 두 주소를, RSS 제출에 RSS 주소를 넣습니다.
    3. 구글 서치 콘솔 (search.google.com/search-console) → URL 접두어에 https://hellomingle.kr → "HTML 태그"로 확인 → Sitemaps 메뉴에 아래 두 주소 제출.
    4. 네이버 플레이스·카카오맵에 매장이 등록돼 있다면, 그 주소를 에 넣어 주세요. 검색엔진이 홈페이지와 매장을 같은 곳으로 묶어 봅니다.
    5. 새 글을 올린 뒤 빨리 검색에 나오게 하고 싶으면 네이버 → 요청 → 웹 페이지 수집에 글 주소를 넣으세요.

    새 글·바뀐 내용 바로 알리기

    글을 새로 올리거나 페이지를 고친 뒤 이 버튼을 누르면, 사이트의 모든 주소를 네이버와 빙(Bing)에 한 번에 알립니다. 검색엔진이 다시 읽으러 오는 시간이 빨라져요. 밍글 소식은 "게시"할 때 자동으로 알리니 따로 누르지 않아도 됩니다.

    구글은 이 방식을 받지 않아요. 구글에는 서치 콘솔의 URL 검사 → 색인 생성 요청을 쓰거나, 사이트맵이 자동으로 읽히기를 기다리면 됩니다.

    AI 검색(ChatGPT · Perplexity · Gemini 등)에 나오려면

    AI는 홈페이지 글, 지도·플레이스 정보, 블로그 후기를 함께 읽고 답을 만듭니다. 홈페이지 쪽 준비는 끝나 있으니, 아래 세 가지만 확인해 주세요.

    1. Cloudflare가 AI 로봇을 막고 있지 않은지 확인 — Cloudflare 대시보드에서 hellomingle.kr을 고르고 보안(Security) 설정의 AI 봇·AI 크롤러 관련 항목을 봐 주세요. "차단(Block)"으로 돼 있으면 홈페이지에서 허용해 두어도 AI가 글을 읽지 못합니다. 검색·답변용 로봇은 허용으로 두는 것을 권해요.
    2. 매장 편의 정보 채우기 — 와이파이, 화장실, 주차, 역에서 걸리는 시간처럼 손님이 AI에게 자주 묻는 것들이에요. 아래 "매장 편의 정보"에 확인된 내용만 적어 주세요.
    3. 지도·플레이스 정보를 홈페이지와 똑같이 맞추기 — 아래 "지도 · 플레이스 등록"을 따라 이름, 주소, 영업시간, 소개글을 같은 표기로 넣습니다. 표기가 서로 다르면 AI가 다른 가게로 볼 수 있어요.

    지도 · 플레이스 등록

    "건대 24시간 카페"처럼 동네 이름이 들어간 검색은 지도 결과가 먼저 나옵니다. 홈페이지만큼 중요해요.

    1. 네이버 스마트플레이스 (smartplace.naver.com) — 업체 등록 또는 내 업체 관리. 영업시간 "24시간", 홈페이지 주소 https://hellomingle.kr, 메뉴 사진과 매장 사진, 아래 소개글과 대표 키워드를 넣어 주세요. 등록 후 플레이스 주소를 에 저장합니다.
    2. 카카오맵 매장관리 (business.kakao.com) — 카카오맵에 매장을 등록하고 영업시간·홈페이지·사진을 넣습니다. 카카오톡 채널과 연결해 두면 문의로 바로 이어져요.
    3. 구글 비즈니스 프로필 (business.google.com) — 구글 지도에는 "Mingle"이라는 이름으로 이미 올라와 있고, 2026년 11월 확인 기준 리뷰가 없습니다. 소유자 확인을 한 뒤 이름을 "밍글 무인카페 건대화양점 (Mingle)"으로 맞추고 홈페이지·사진·영업시간을 채워 주세요. 외국인 손님과 AI 검색은 구글 지도를 많이 참고합니다.
    4. 빙 웹마스터 도구 (bing.com/webmasters) — 구글 서치 콘솔 계정으로 가져오기를 누르면 바로 등록됩니다. ChatGPT 검색이 빙의 검색 결과를 함께 참고하는 것으로 알려져 있어 등록해 두는 편이 좋아요.
    5. 후기 부탁하기 — 매장 안 QR 옆에 "네이버 플레이스 후기" 안내를 붙여 두세요. 실제 손님 후기가 쌓여야 지도 검색 순위와 AI 추천이 함께 올라갑니다. 대가를 걸고 후기를 받는 것은 각 서비스 정책에 어긋나니 피해 주세요.

    한 줄 소개

    건대입구역 근처 화양동의 24시간 무인 디저트카페. 넓은 좌석과 창가 콘센트 자리, 커피와 케이크·구움과자가 있어요.

    소개글 (플레이스 · 카카오맵)

    밍글은 서울 광진구 화양동, 건대입구역 근처에 있는 24시간 무인 디저트카페입니다. 약 30평 매장에 창가 콘센트 자리와 테이블, 소파석이 있고, 키오스크에서 카드나 간편결제로 주문합니다. 커피와 말차 라떼·밀크티·에이드, 조각 케이크와 푸딩, 쿠키·휘낭시에·마들렌 같은 구움과자를 준비해 두었어요. 이용 시간 제한이 없어 밤늦게 공부하거나 작업하기에도 괜찮고, 디저트만 포장해 가셔도 됩니다. 홈페이지(hellomingle.kr)에서 오늘의 메뉴와 동네 게시판 밍글보드, 모임 소식을 볼 수 있어요.

    영문 소개 (구글 비즈니스 프로필)

    Mingle is a 24-hour self-service dessert café near Konkuk University Station in Hwayang-dong, Seoul. Order at the kiosk (card or mobile pay only), enjoy machine-brewed coffee, cakes and baked sweets, and stay as long as you like. Window seats have power outlets.
